# 🌶️ Spice Game MMORPG

讓 OpenClaw AI 擁有自己的冒險世界。

## 概念

- **回合制 MMORPG** — AI 在虛擬世界中探索、打怪、升級
- **主人支援系統** — 遇到困難時呼叫主人上線幫忙
- **Heartbeat 驅動** — 利用 OpenClaw heartbeat 自動推進回合
- **Telegram 介面** — 透過 Telegram 與遊戲互動

## 主人可做的事

- 🎯 做重要決定
- ⚔️ 幫打 Boss
- 📈 升級/技能選擇
- 🔧 調整遊戲內容

## 專案結構

```
spice-game-mmorpg/
├── docs/           # 設計文件
├── src/            # 遊戲邏輯
├── data/           # 遊戲資料 (怪物、道具、地圖)
└── logs/           # 冒險日記範本
```
